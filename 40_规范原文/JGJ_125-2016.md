# JGJ 125-2016 危险房屋鉴定标准

## 概述
危险房屋鉴定专用标准。定义危险构件判定（地基/基础/砌体/混凝土/钢）、两阶段综合评定（地基优先→加权比例法）、A/B/C/D 四级房屋评级、四类处理建议。被 [[DB11_T_849-2021#条文3.0.9]] 直接衔接。

---

## 适用范围与定义

### 条文 1.0.2 & 2.1.11
- 适用范围：高度 **≤100m** 既有房屋
- **危险房屋**：房屋结构体系中存在承重构件被评定为危险构件，导致局部或整体不能满足安全使用要求的房屋

---

## 危险性等级划分

### 条文 6.1.3 基础及楼层评级
| 等级 | 含义 |
|-----|------|
| **A 级** | 无危险点 |
| **B 级** | 有危险点 |
| **C 级** | 局部危险 |
| **D 级** | 整体危险 |

### 条文 6.1.4 房屋整体评级
| 等级 | 含义 | 处理 |
|-----|------|------|
| **A 级** | 无危险构件，满足安全使用 | — |
| **B 级** | 个别危险构件，不影响主体 | 基本满足 |
| **C 级** | 部分承重结构不满足，**局部危房** | 应处理 |
| **D 级** | 承重结构不满足，**整幢危房** | 必须处理 |

## 地基危险性鉴定

### 条文 4.2.1 单层/多层房屋地基危险判定（5 条）
1. 自然状态：沉降 **>4mm/月** 连续两月且无收敛；施工影响：**>2mm/天** 无收敛
2. 砌体承重墙单条沉降裂缝 **>10mm**，或平行裂缝 **>5mm** 多条，且倾斜率 **>10‰**
3. 混凝土框架梁柱因沉降开裂，且倾斜率 **>10‰**
4. 二层以下倾斜 **>30‰**，三层以上 **>20‰**
5. 地基滑移水平位移 **>10mm**，且继续滑动

### 条文 4.2.2 高层房屋地基危险判定
1. 倾斜率增速连续两月 **>0.5‰/月**，无收敛
2. 沉降开裂持续发展
3. 整体倾斜率超限值：
   - 24<H≤60m → **7‰**
   - 60<H≤100m → **5‰**

## 基础构件危险点

### 条文 5.2.3
1. 承载力：$R/(γ₀S) < 0.90$
2. 基础老化/腐蚀/酥碎/折断导致上部明显倾斜/位移/裂缝/扭曲，或连接处裂缝 **>10mm**
3. 基础滑动水平位移速度 **>2mm/月** 连续两月无收敛

→ 检测项目：[[地基承载力检测]]

## 砌体结构危险点（10 条）

### 条文 5.3.3
| # | 危险点 |
|---|--------|
| 1 | 承载力：主要构件 R/(γ₀S)<**0.90**，一般构件 <**0.85** |
| 2 | 承重墙/柱竖向裂缝 **>1.0mm**，缝长 >层高 1/2；或多条缝长 >层高 1/3 |
| 3 | 风化/剥落/砂浆粉化 → 有效截面削弱 **≥15%** |
| 4 | 梁/屋架支座下砌体多条竖向裂缝，或缝宽 **>1.0mm** |
| 5 | 偏心受压产生**水平裂缝** |
| 6 | 局部倾斜 **>7‰**，或相邻构件连接处断裂成通缝 |
| 7 | 侧弯矢高 **>h/150**，或挠曲部位出现水平/交叉裂缝 |
| 8 | 砖过梁中部竖向裂缝或端部斜裂缝，或明显弯曲下挠 |
| 9 | 砖拱/扁壳/波形筒拱拱顶沿母线裂缝、拱曲面变形、拱脚位移、拉杆锈蚀失效 |
| 10 | 高厚比 **>1.2 倍** GB 50003 允许值 |

## 整体综合评定

### 条文 6.2 评定原则
**两阶段鉴定**：
1. 第一阶段：地基危险 → 直接 D 级整幢危房；地基非危险 → 进入第二阶段
2. 第二阶段：综合基础+上部结构评定

考虑因素：损伤程度、重要性与比例、关联作用、环境影响、可修复性。

### 条文 6.3 加权比例法

**楼层危险构件综合比例**（6.3.2）：按构件重要性加权——中柱×3.5、边柱×2.7、角柱×1.8、墙体×2.7、屋架×1.9、中梁×1.9、边梁×1.4……

**楼层评级**（6.3.3）：

| R 范围 | 楼层等级 |
|--------|---------|
| R = 0 | A 级 |
| 0 < R < 5% | B 级 |
| 5% ≤ R < 25% | C 级 |
| R ≥ 25% | **D 级** |

**房屋整体评级**（6.3.5）：

| R 范围 | 条件 | 等级 |
|--------|------|------|
| R = 0 | 各层均 A 级 | A |
| 0 < R < 5% | 各层无 D 级 → B；否则 → C | B/C |
| 5% ≤ R < 25% | D 级层数 ≤(F+B+f)/3 → C；否则 → D | C/D |
| R ≥ 25% | — | **D** |

## 鉴定报告与处理建议

### 条文 7.0.1 报告内容（6 项）
建筑概况、鉴定目的/范围/依据、调查检测分析过程及结果、评定等级、结论建议、附件

### 条文 7.0.4 危险构件处理措施
减少荷载、加固更换、临时支撑、观察使用或停止使用、拆除部分或全部

### 条文 7.0.5 危房处理方式（四类）
| 方式 | 适用条件 |
|------|---------|
| **观察使用** | 采取安全措施后尚能短期使用，需继续观察 |
| **处理使用** | 采取技术措施后可解除危险 |
| **停止使用** | 已无修缮价值，暂时不便拆除，不危及相邻建筑 |
| **整体拆除** | 整幢危险且无修缮价值，需立即拆除 |
