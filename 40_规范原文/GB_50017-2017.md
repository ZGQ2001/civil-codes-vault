# GB 50017-2017 钢结构设计标准

## 概述

钢结构检测鉴定的**母规范**——所有钢结构验收偏差、强度复核、变形判定均需回溯到此标准的设计容许值。

## 条文 4.4.1 — 钢材强度设计值

## 条文 4.4.5 — 焊缝强度设计值

对接焊缝在受压区取 f_c^w，受拉区取 f_t^w。

**折减系数**（连乘）：
- 高空安装焊缝 ×0.9
- 无垫板单面焊对接焊缝 ×0.85

## 条文 11.3.5/11.3.6 — 焊缝构造

### 焊脚尺寸 h_f

**最小 h_f**（表 11.3.5）：
| 母材厚度 t (mm) | 最小 h_f (mm) |
|-----------------|--------------|
| t ≤ 6 | 3 |
| 6 < t ≤ 12 | 5 |
| 12 < t ≤ 20 | 6 |
| t > 20 | 8 |

承受动荷载时 h_f ≥ 5mm。（注：2017 版不再采用 1.5√t_max 公式，改为直接查表。）

**最大 h_f**（搭接焊缝沿母材棱边）：
| 板厚 t | 最大 h_f |
|---------|---------|
| t ≤ 6mm | t（母材厚度） |
| t > 6mm | t − (1~2)mm |

### 计算长度

- 最小计算长度 = 8h_f，且 ≥ 40mm
- 计算长度 = 焊缝全长 − 引弧/收弧长度

### 搭接连接

传递轴向力时，最小搭接长度 = 5×较薄件厚度，且 ≥ 25mm。
应施焊纵向或横向双角焊缝。

## 条文 11.5.2 — 螺栓间距与边距

### 最小容许值

| 位置 | 最小容许值 |
|------|-----------|
| 中心间距（外排/中间排） | **3d₀** |
| 端距（顺内力方向） | **2d₀** |
| 边距 · 剪切边或手工气割边 | 1.5d₀ |
| 边距 · 轧制/自动气割/锯割边（高强螺栓） | 1.2d₀ |
| 边距 · 轧制/自动气割/锯割边（其他螺栓） | 1.5d₀ |

### 最大容许值（取较小值）

| 位置 | 最大容许值 |
|------|-----------|
| 外排（垂直或顺内力） | **8d₀** 或 **12t** |
| 中间排 · 构件受压力 | 12d₀ 或 18t |
| 中间排 · 构件受拉力 | 16d₀ 或 24t |
| 边距（垂直内力方向） | 4d₀ 或 8t |

> d₀ = 螺栓孔径；t = 较薄板件厚度

## 条文 17.1.4 + 附录 B.2 — 结构位移限值

### 风荷载下弹性层间位移角

| 工况 | 限值 |
|------|------|
| 多层钢结构 · 有桥式起重机 | **1/400** |
| 多层钢结构 · 无桥式起重机（框架/框架-支撑） | **1/250** |
| 高层建筑钢结构（风荷载+多遇地震） | **1/250** |

### 罕遇地震弹塑性层间位移角

按 GB 50011 / GB 50191 执行。当构造满足延性等级 Ⅰ 级时，限值可增加 25%。
