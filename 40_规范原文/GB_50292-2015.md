# GB 50292-2015 民用建筑可靠性鉴定标准

## 概述
民用建筑可靠性鉴定的总纲。定义三套评级体系（安全性/使用性/可靠性）、三级层次（构件→子单元→鉴定单元）、各类构件的承载力分级和裂缝挠度限值。

---

## 适用范围与定义

### 条文 1.0.2 适用范围
**条文原文：**
本标准适用于以混凝土结构、钢结构、砌体结构、木结构为承重结构的民用建筑及其附属构筑物的可靠性鉴定。

### 条文 2.1.6~2.1.8 三类鉴定定义
**条文原文：**
- **可靠性鉴定**：对民用建筑承载能力和整体稳定性等的安全性以及适用性和耐久性等的使用性所进行的调查、检测、分析、验算和评定等一系列活动。
- **安全性鉴定**：对民用建筑的结构承载力和结构整体稳定性所进行的调查、检测、验算、分析和评定等一系列活动。
- **使用性鉴定**：对民用建筑使用功能的适用性和耐久性所进行的调查、检测、分析、验算和评定等一系列活动。

## 鉴定触发条件

### 条文 3.1.1 何时做鉴定
**条文原文：**
民用建筑可靠性鉴定，应符合下列规定：

**应进行可靠性鉴定（6 种）**：
1. 建筑物大修前；
2. 建筑物改造或增容、改建或扩建前；
3. 建筑物改变用途或使用环境前；
4. 建筑物达到设计使用年限拟继续使用时；
5. 遭受灾害或事故时；
6. 存在较严重的质量缺陷或出现较严重的腐蚀、损伤、变形时。

**可仅进行安全性鉴定（4 种）**：
1. 各种应急鉴定；
2. 国家法规规定的房屋安全性统一检查；
3. 临时性房屋需延长使用期限；
4. 使用性鉴定中发现安全问题。

**可仅进行使用性鉴定（2 种）**：
1. 建筑物使用维护的常规检查；
2. 建筑物有较高舒适度要求。

**应进行专项鉴定（4 种）**：
1. 结构的维修改造有专门要求时；
2. 结构存在耐久性损伤影响其耐久年限时；
3. 结构存在明显的振动影响时；
4. 结构需进行长期监测时。

→ 检测项目：[[结构可靠性鉴定]]

## 三套评级体系

### 条文 3.3.1 安全性鉴定评级（构件→子单元→鉴定单元）

| 层次 | 对象 | 等级 | 含义 | 处理 |
|-----|------|-----|------|------|
| 一 | 单个构件 | **aᵤ** | 安全，足够承载 | 不必 |
| | | **bᵤ** | 略低于 aᵤ，不显著影响 | 可不 |
| | | **cᵤ** | 不符合 aᵤ，显著影响 | 应 |
| | | **dᵤ** | 极不符合 aᵤ，严重影响 | 必须立即 |
| 二 | 子单元 | **Aᵤ** | 安全，不影响整体 | 可能有个别 |
| | | **Bᵤ** | 略低于 Aᵤ | 极少数 |
| | | **Cᵤ** | 不符合 Aᵤ，显著影响 | 应 + 极少数立即 |
| | | **Dᵤ** | 极不符合 Aᵤ，严重影响 | 必须立即 |
| 三 | 鉴定单元 | **Aₛᵤ** | 安全 | 极少数一般 |
| | | **Bₛᵤ** | 略低于 Aₛᵤ | 极少数 |
| | | **Cₛᵤ** | 不符合 Aₛᵤ | 应 + 极少数及时 |
| | | **Dₛᵤ** | 严重不符合 Aₛᵤ | 必须立即 |

### 条文 3.3.2 使用性鉴定评级（构件→子单元→鉴定单元）

| 层次 | 等级 | 含义 |
|-----|------|------|
| 构件 | **aₛ / bₛ / cₛ** | 正常使用 / 略低 / 显著影响 |
| 子单元 | **Aₛ / Bₛ / Cₛ** | 不影响整体 / 略低 / 显著影响 |
| 鉴定单元 | **Aₛₛ / Bₛₛ / Cₛₛ** | 同上 |

> 注：当仅对耐久性问题进行专项鉴定时，表中"使用性"可直接改称为"耐久性"。

### 条文 3.3.3 可靠性鉴定评级（综合安全+使用）

| 层次 | 对象 | 等级 | 处理 |
|-----|------|-----|------|
| 一 | 单个构件 | **a / b / c / d** | 不必 / 可不 / 应 / 必须立即 |
| 二 | 子单元 | **A / B / C / D** | 同上 |
| 三 | 鉴定单元 | **Ⅰ / Ⅱ / Ⅲ / Ⅳ** | 同上 |

## 混凝土构件安全性鉴定

### 条文 5.2.2 承载力分级 R/(γ₀S)

| 构件类别 | aᵤ 级 | bᵤ 级 | cᵤ 级 | dᵤ 级 |
|---------|--------|--------|--------|--------|
| **主要构件及节点连接** | ≥1.00 | ≥0.95 | ≥0.90 | <0.90 |
| **一般构件** | ≥1.00 | ≥0.90 | ≥0.85 | <0.85 |

### 条文 5.2.3 构造评定

| 检查项目 | aᵤ/bᵤ 级 | cᵤ/dᵤ 级 |
|---------|----------|----------|
| 结构构造 | 合理，符合规范 | 不当，有明显缺陷 |
| 连接/节点构造 | 连接方式正确，无缺陷或仅表面缺陷 | 连接不当，已导致变形/滑移/拉脱/剪坏/裂缝 |
| 受力预埋件 | 构造合理，无变形/滑移/松动 | 构造缺陷，已导致变形/滑移/松动/损坏 |

## 混凝土构件使用性鉴定

### 条文 6.2.2 挠度评定
1. 检测值 < 计算值及规范限值 → **aₛ 级**
2. 计算值 ≤ 检测值 ≤ 规范限值 → **bₛ 级**
3. 检测值 > 规范限值 → **cₛ 级**

### 条文 6.2.4 裂缝宽度评定

**钢筋混凝土构件裂缝宽度限值（表 6.2.4-1）**

| 环境类别 | 构件种类 | aₛ 级 | bₛ 级 | cₛ 级 |
|---------|---------|------|------|------|
| I-A | 主要构件 | <0.15mm | ≤0.20mm | >0.20mm |
| I-A | 一般构件 | <0.20mm | ≤0.30mm | >0.30mm |
| I-B、I-C | 任何构件 | <0.15mm | ≤0.20mm | >0.20mm |
| II | 任何构件 | <0.10mm | ≤0.15mm | >0.15mm |
| III、IV | 任何构件 | 无肉眼可见裂缝 | <0.10mm | >0.10mm |

**预应力混凝土构件裂缝宽度限值（表 6.2.4-2）**

| 环境类别 | 构件种类 | aₛ 级 | bₛ 级 | cₛ 级 |
|---------|---------|------|------|------|
| I-A | 主要构件 | 无裂缝(<0.05) | <0.05(≤0.10) | >0.05(>0.10) |
| I-A | 一般构件 | ≤0.02(<0.15) | <0.10(≤0.25) | >0.10(>0.25) |
| I-B、I-C | 任何构件 | 无裂缝 | ≤0.02(<0.05) | >0.02(>0.05) |
| II~IV | 任何构件 | 无裂缝 | 无裂缝 | 有裂缝 |

> 注：沿主筋方向出现锈迹或细裂缝 → 直接评为 **cₛ 级**。
> 括号内限值仅适用于热轧钢筋配筋的预应力混凝土构件。

## 子单元安全性评级

### 条文 7.2.3 地基基础——按沉降评级

| 等级 | 判定条件 |
|------|---------|
| **Aᵤ** | 不均匀沉降 < 规范允许值；无沉降裂缝/变形/位移 |
| **Bᵤ** | 不均匀沉降 ≤ 规范值；连续两月沉降 <2mm/月；上部轻微裂缝无发展 |
| **Cᵤ** | 不均匀沉降 > 规范值；或连续两月 >2mm/月；或砌体裂缝 >5mm / 预制构件连接裂缝 >1mm，且无终止趋势 |
| **Dᵤ** | 不均匀沉降远大于规范值；连续两月 >2mm/月且变快；砌体裂缝 >10mm / 预制构件裂缝 >3mm / 现浇结构出现沉降裂缝 |

> 注：以上沉降标准仅适用于建成 ≥2 年、一般地基土上的建筑物。

### 条文 7.2.4 地基基础——按承载力评级
- 承载力符合规范 → 按完好程度评为 Aᵤ 或 Bᵤ
- 承载力不符合规范 → 按开裂损伤程度评为 Cᵤ 或 Dᵤ

### 条文 7.3.5 主要构件集安全性评级（含量百分比）

| 等级 | 多层及高层房屋 | 单层房屋 |
|-----|-------------|---------|
| **Aᵤ** | 无 cᵤ/dᵤ，bᵤ≤25% | 无 cᵤ/dᵤ，bᵤ≤30% |
| **Bᵤ** | 无 dᵤ，cᵤ≤15% | 无 dᵤ，cᵤ≤20% |
| **Cᵤ** | 仅 cᵤ≤40% / 仅 dᵤ≤10% / cᵤ≤25%+dᵤ≤3% | 仅 cᵤ≤50% / 仅 dᵤ≤15% / cᵤ≤30%+dᵤ≤5% |
| **Dᵤ** | cᵤ/dᵤ 多于 C 级规定 | 同上 |

### 条文 7.3.8 上部结构承载功能等级
- **Aᵤ**：无 Cᵤ/Dᵤ 代表层，Bᵤ≤30%
- **Bᵤ**：无 Dᵤ 代表层，Cᵤ≤15%
- **Cᵤ**：仅 Cᵤ≤50% / 仅 Dᵤ≤10% / Cᵤ≤25%+Dᵤ≤5%
- **Dᵤ**：Cᵤ/Dᵤ 多于 C 级规定

### 条文 7.3.9 结构整体牢固性（4 项检查）
| 检查项目 | Aᵤ/Bᵤ | Cᵤ/Dᵤ |
|---------|-------|-------|
| 结构布置及构造 | 合理，符合规范 | 不合理，存在薄弱环节 |
| 支撑系统/抗侧力系统 | 符合规范，无残损 | 不符合规范，连接失效 |
| 结构构件间联系 | 设计合理，连接可靠 | 设计不合理，连接不当 |
| 砌体圈梁及构造柱 | 符合规范，无裂缝 | 不符合规范，已开裂 |

### 条文 7.3.11 综合评级与降级
- 取承载功能和侧向位移的**较低一级**
- Bᵤ 降为 Cᵤ：cᵤ 构件交汇节点 / cᵤ 存在于人群密集场所
- Cᵤ 降为 Dᵤ：底层柱集为 Cᵤ/Dᵤ / 人群密集处有 dᵤ / 50% 以上构件为 cᵤ
- Aᵤ/Bᵤ 但整体性为 Cᵤ/Dᵤ → 降为 Cᵤ

## 鉴定报告

### 条文 12.0.1 报告内容（5 项）
1. 建筑物概况
2. 鉴定的目的、范围和内容
3. 检查、分析、鉴定的结果
4. 结论与建议
5. 附件

### 条文 12.0.2 cᵤ/dᵤ 构件说明
鉴定报告中，应对 cᵤ 级、dᵤ 级构件及 Cᵤ 级、Dᵤ 级检查项目的数量、所处位置及其处理建议，逐一作出详细说明。当房屋的构造复杂或问题很多时，尚应绘制分布图。

### 条文 12.0.5 结果说明
1. 等级仅作为技术管理或制定维修计划的依据；
2. 即使所评等级较高，也应及时对其中所含的 cᵤ 级、dᵤ 级构件及 Cᵤ 级、Dᵤ 级检查项目采取加固或拆换措施。
