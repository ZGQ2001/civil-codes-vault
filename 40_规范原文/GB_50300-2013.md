# GB 50300-2013 建筑工程施工质量验收统一标准

## 概述
建筑施工质量验收的总纲。定义单位工程→分部→分项→检验批四级划分、各层验收程序与组织、合格条件、抽样方案。

---

## 验收层次划分

### 条文 4.0.1~4.0.5 四级划分

| 层次 | 划分原则 | 条文 |
|------|---------|------|
| **单位工程** | 独立施工 + 独立使用功能的建筑物/构筑物 | 4.0.2 |
| **子单位工程** | 规模较大时，能形成独立使用功能的部分 | 4.0.2 |
| **分部工程** | 按专业性质、工程部位；较大时按材料种类/施工特点划分子分部 | 4.0.3 |
| **分项工程** | 按主要工种、材料、施工工艺、设备类别 | 4.0.4 |
| **检验批** | 按工程量、楼层、施工段、变形缝 | 4.0.5 |

> 附录 B 给出了分部/分项工程的完整划分表。

## 验收合格条件

### 条文 5.0.1 检验批合格条件
1. **主控项目**：经抽样检验均应合格；
2. **一般项目**：合格点率应符合专业验收规范规定，不得存在严重缺陷。计数抽样可按附录 D 判定；
3. 具有完整的施工操作依据、质量验收记录。

### 条文 5.0.2 分项工程合格条件
1. 所含检验批的质量均应验收合格；
2. 所含检验批的质量验收记录应完整。

### 条文 5.0.3 分部工程合格条件
1. 所含分项工程的质量均应验收合格；
2. 质量控制资料应完整；
3. **安全、节能、环境保护和主要使用功能**的抽样检验结果应符合相应规定；
4. 观感质量应符合要求。

### 条文 5.0.4 单位工程合格条件
1. 所含分部工程的质量均应验收合格；
2. 质量控制资料应完整；
3. 所含分部工程中有关安全、节能、环境保护和主要使用功能的检验资料应完整；
4. 主要使用功能的抽查结果应符合相关专业验收规范的规定；
5. 观感质量应符合要求。

## 验收程序与组织

| 层次 | 组织者 | 参加者 | 条文 |
|-----|--------|------|------|
| **检验批** | 专业监理工程师 | 施工单位项目专业质量检查员、专业工长 | 6.0.1 |
| **分项工程** | 专业监理工程师 | 施工单位项目专业技术负责人 | 6.0.2 |
| **分部工程** | **总监理工程师** | 施工单位项目负责人、技术负责人；地基/主体/节能 → 勘察设计项目负责人+质量部门负责人 | 6.0.3 |
| **竣工预验收** | 总监理工程师 | 各专业监理工程师 | 6.0.5 |
| **单位工程** | **建设单位项目负责人** | 监理、施工、设计、勘察单位项目负责人 | 6.0.6 |

> 分包工程：分包自检 → 总包参加验收 → 分包移交资料给总包（6.0.4）

→ 判定：[[验收程序与组织]]

## 抽样方案

### 条文 3.0.4 抽样数量调整条件
符合下列条件之一时，可适当调整抽样复验数量（方案由施工单位编制 + 监理审核）：
1. 同一项目多个单位工程，使用同一厂家同品种、同规格、同批次材料/构配件/设备；
2. 同一施工单位现场加工的成品/半成品/构配件用于同一项目多个单位工程；
3. 同一项目中针对同一抽样对象已有检验成果可重复利用。

### 条文 3.0.8 抽样方案选择
1. 计量、计数或计量-计数抽样；
2. 一次、二次或多次抽样；
3. 重要项目有简易快速方法时 → 全数检验；
4. 根据生产连续性和稳定性 → 调整型抽样；
5. 经实践证明有效的抽样方案。

### 条文 3.0.9 最小抽样数量表
**条文原文：**
检验批抽样样本应随机抽取，满足分布均匀、具有代表性的要求。当采用计数抽样时，最小抽样数量应符合表 3.0.9。

| 检验批容量 | 最小抽样数量 |
|----------|------------|
| 2~15 | 2 |
| 16~25 | 3 |
| 26~90 | 5 |
| 91~150 | 8 |
| 151~280 | 13 |
| 281~500 | 20 |
| 501~1200 | 32 |
| 1201~3200 | 50 |

> 明显不合格的个体可不纳入检验批，但应处理并记录后重新验收。

### 条文 3.0.10 错判/漏判概率
- **主控项目**：α 和 β 均不宜超过 **5%**
- **一般项目**：α 不宜超过 5%，β 不宜超过 **10%**
