# 结构外观质量检测

## 缺陷等级
按 [[外观缺陷等级划分]] 分为 **严重缺陷** 和 **一般缺陷**。

## 九类外观缺陷
| 缺陷类型 | 严重缺陷判定 |
|---------|-----------|
| 露筋 | 纵向受力钢筋外露 |
| 蜂窝 | 主要受力部位 |
| 孔洞 | 主要受力部位 |
| 夹渣 | 主要受力部位 |
| 疏松 | 主要受力部位 |
| 裂缝 | 影响结构性能或使用功能 |
| 连接部位缺陷 | 影响结构传力性能 |
| 外形缺陷 | 清水混凝土影响使用功能或装饰效果 |
| 外表缺陷 | 重要装饰效果的清水混凝土 |
