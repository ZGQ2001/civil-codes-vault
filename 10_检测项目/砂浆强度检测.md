# 砂浆强度检测

## 检测方法

### 推出法
- 240mm 墙，砂浆 1~15MPa
- 饱满度 <65% 不宜用
- 依据：[[GB_T_50315#条文9.1.1]]

### 筒压法
- 凿取砂浆 4000g → 筛 5~15mm → 烘干 → 分 3 试样
- 装入承压筒跳振 → 加荷至规定值（水泥砂浆 20kN / 混合砂浆 10kN）
- 卸荷后再筛分称重
- 依据：[[GB_T_50315#条文10.3.1]]

### 点荷法
- 砂浆片 5~12mm 厚，1min 左右破坏
- 测量荷载作用半径
- 依据：[[GB_T_50315#条文13.3.1]]

### 砂浆回弹法
- 无损，≥2MPa，灰缝表面需平整
- 依据：[[GB_T_50315]] 表 3.4.3

## 强度推定
### 新建工程（≥6 测区）
$f'_2 = \min(0.91f_{2,m},\; 1.18f_{2,min})$

### 既有建筑
$f'_2 = \min(f_{2,m},\; 1.33f_{2,min})$（GB 50203-2002 及以前）

### 边界
<2MPa 或 >15MPa → 仅给范围
