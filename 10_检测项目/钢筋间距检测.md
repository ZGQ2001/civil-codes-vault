# 钢筋间距检测

## 允许偏差（GB 50204-2015 表5.5.3）

| 钢筋类型 | 允许偏差 |
|---------|---------|
| 纵向受力钢筋间距 | **±10mm** |
| 绑扎箍筋、横向钢筋间距 | **±20mm** |

## 检测方法

### 电磁感应法
- 预扫描：探头沿垂直钢筋方向移动
- 将设计间距相同的连续相邻钢筋**逐一标出并逐个量测**
- 连续量测数量 ≥ **6 个**
- 依据：[[JGJ_T_152-2019#条文4.4.3]] · [[JGJ_T_152-2019#条文4.4.5]]

### 雷达法
- 探头/天线沿垂直被测钢筋轴线方向扫描
- 场地允许时使用天线阵雷达**网格状扫描**
- 依据：[[JGJ_T_152-2019#条文4.5.2]]

## 合格判定

梁/柱/墙/板类构件钢筋的**平均间距**与设计要求的偏差 ≤ 允许偏差 → 判定为符合设计要求。

依据：[[GB_T_50784-2013#条文9.2.6]]

### calc_rebar_spacing 伪代码
```
输入: spacings (≥6个间距值), design_spacing, bar_type ∈ {纵向, 箍筋/横向}
判定:
  avg = mean(spacings)
  delta = avg - design_spacing
  查表获取允许偏差
  |delta| ≤ 允许偏差 → PASS
输出: CalcResult(passed, avg, delta)
```
