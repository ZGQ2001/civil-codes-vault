# 钢材硬度检测（里氏硬度）

> **属性：[B. 既有鉴定]**（新建验收以材质证明文件为准，现场硬度检测主要用于既有建筑）

## 抗拉强度换算

$$f_b = 0.952 \times HLD + 167$$

- $f_b$：抗拉强度（MPa）
- $HLD$：里氏硬度代表值（D 型冲击装置）
- 依据：[[DB62_T_25-3126-2016#条文4.2.7]]

## 测点布置

| 要求 | 数值 |
|------|------|
| 每构件测区 | ≥ **3 个** |
| 每测区测点 | **9 点**（均匀分布） |
| 测点间距 | > **4mm** |
| 距边缘距离 | ≥ **5mm** |
- 依据：[[GB_T_50344-2004#条文N.2.2]]

## 代表值计算

1. 9 个测试值中剔除 **2 个最大值 + 2 个最小值**
2. 取余下 **5 个**的算术平均值
3. 作为该测区里氏硬度代表值 $HLD$
- 依据：[[GB_T_50344-2004#条文N.2.5]]

## 合格判定

- 将 $HLD$ 代入换算公式得 $f_b$
- 与设计要求的钢材抗拉强度比较
- 依据：[[GB_T_50344-2004#条文N.3.1]]

### ⚠️ 限制
里氏硬度为**间接推定法**。当推定值处于设计强度等级临界附近或有争议时，必须辅以**取样拉伸试验**（GB/T 2975）交叉验证。

### calc_hardness 伪代码
```
输入: values (9个里氏硬度值)
判定:
  排序 → 剔除2最大+2最小 → 取5个均值 = HLD
  f_b = 0.952 × HLD + 167
  f_b ≥ 设计强度下限 → PASS
输出: CalcResult(passed, HLD, f_b)
```
