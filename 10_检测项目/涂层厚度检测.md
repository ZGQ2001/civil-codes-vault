# 涂层厚度检测

## 防腐涂层

### 判定公式

| 条件 | 公式 |
|------|------|
| 设计有要求 | 每处3点均值 ≥ 设计×0.85 **且** 构件15点总均值 ≥ 设计 |
| 设计无要求 | 室外 ≥ 125µm（150µm−25µm），室内 ≥ 100µm（125µm−25µm） |
| 允许偏差 | −25µm |

### 测点布置
- 每构件 **5处 × 3点**（间距 50mm）
- 测厚仪 **二点校准**（同基体标准片），关机重启需重校
- 依据：[[GB_T_50621-2010#条文12.1.3]] · [[GB_T_50621-2010#条文12.4.1]] · [[GB_50205-2020#条文13.2.3]]

### calc_coating_thickness 伪代码
```
输入: values (15个测点值 = 5处 × 3点), design_thickness, coating_type="防腐"
判定:
  for each 处 (3点):
    处均值 ≥ design × 0.85 → 该处合格
  总均值 ≥ design → 构件合格
  两者都满足 → PASS
输出: CalcResult(passed, 各处均值, 总均值)
```

## 防火涂层

### 判定公式

| 类型 | 判定 |
|------|------|
| 膨胀型（超薄/薄涂） | 偏差 ≥ −5% 设计值 |
| 厚涂型 | ≥80% 面积满足耐火极限要求 **且** 最薄处 ≥ 设计×0.85 |

### 测点布置（GB/T 50621）
- **楼板/墙体**：两相邻轴线围合面对角线，每米 1 点，≥5 点/构件
- **梁/柱**：每 3m 一截面，≥2 截面/构件
- 工具：探针 + 卡尺
- 依据：[[GB_T_50621-2010#条文13.1.3]] · [[GB_T_50621-2010#条文13.1.4]]

### 验收抽查（GB 50205）
- 按构件数 **10%**，≥3 件
- 依据：[[GB_50205-2020#条文13.4.3]]

### 裂纹限值
| 类型 | 允许裂纹 |
|------|---------|
| 超薄型 | 不允许 |
| 薄涂型 | ≤0.5mm |
| 厚涂型 | ≤1.0mm |
- 依据：[[GB_50205-2020#条文13.4.4]]

### 粘结强度
- 薄涂型：每 100t 抽检一次
- 厚涂型：每 500t 抽检一次
- 依据：[[GB_50205-2020#条文13.4.2]]

### 附着力
- 腐蚀介质环境/外露时需测
- 涂层完整程度 ≥70% → 合格
- 方法：GB 1720 / GB/T 9286

### 外观
- 均匀，无皱皮/流坠/针眼/气泡，全数检查

## 验收 vs 鉴定

| 维度 | [A] 新建验收 | [B] 既有鉴定 |
|------|-------------|-------------|
| 判定逻辑 | 85%规则 + 15点均值 ≥ 设计 | 评估涂层剩余防护寿命与锈蚀程度 |
| 超限处理 | 不合格 | 涂层局部脱落属正常老化，描述现状并评估耐久性影响 |
| 结论形式 | 合格/不合格 | 耐久性评估，非单纯厚度合格率 |
