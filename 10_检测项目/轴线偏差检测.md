# 轴线偏差检测

## 混凝土结构（GB 50204-2015）

### 轴线位置

| 项目 | 允许偏差 |
|------|---------|
| 柱/墙/梁轴线位置 | **8mm** |
| 全高（H）垂直度 | **H/1000，且 ≤30mm** |

### 验收抽样
- 施工检验批：梁/柱抽查 **10%**，≥3 件；墙/板抽查 **10%**，≥3 间
- 结构实体：梁/柱抽取 **1%**，≥3 个；墙/板抽取 **1%**，≥3 间

---

## 钢结构（GB 50205-2020 第10章）

### 轴线位置

| 项目 | 允许偏差 |
|------|---------|
| 基础柱定位轴线 | **1.0mm** |
| 柱脚底座中心线对定位轴线 | **5.0mm** |
| 柱子定位轴线 | **1.0mm** |
| 钢桁架/梁支座中心（混凝土柱上） | ≤ **10mm** |

### 整体垂直度（表10.9.1）

| 结构类型 | 允许偏差 |
|---------|---------|
| 单层结构 | **H/1000**，≤ **25.0mm** |
| 多高层 H≤60m | **(H/2500+10)mm**，≤ **30.0mm** |
| 高层 60m<H≤100m | **(H/2500+10)mm**，≤ **50.0mm** |
| 高层 H>100m | **(H/2500+10)mm**，≤ **80.0mm** |

### 验收抽样
- 钢柱安装偏差：按柱数 **10%**，≥3 件
- 钢梁安装偏差：按梁数 **10%**，≥3 件
- 整体垂直度：主要立面**全部检查**，除两角柱外至少一列中间柱
- 依据：[[GB_50205-2020#条文10.3.4]] · [[GB_50205-2020#条文10.9.1]]

### calc_axis_deviation 伪代码
```
输入: measured, structure_type ∈ {混凝土, 钢结构}, member_type, H (高度)
判定:
  if 混凝土:
    axis: |measured| ≤ 8mm → PASS
    verticality: H_measured ≤ H/1000 且 ≤ 30mm → PASS
  else 钢结构:
    查表: 按结构类型和高度取 H/N+f(H) 限值
    |measured| ≤ limit → PASS
输出: CalcResult(passed, measured, limit)
```
