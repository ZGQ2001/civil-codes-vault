# 倾斜检测

## 允许值（按高度分级）

| 建筑高度 H_g | 允许倾斜 |
|-------------|---------|
| ≤ 24m | **≤ 0.004** |
| 24m < H_g ≤ 60m | **≤ 0.003** |
| 60m < H_g ≤ 100m | **≤ 0.0025** |
| > 100m | **≤ 0.002** |

## 测量方法（经纬仪/全站仪）

### 测点布置
- 测站点：与倾斜方向一致（或正交）的方向线上，距照准目标 **1.5~2.0 倍**目标高度
- 测站点数量 ≥ **2 个**
- 上下观测点沿建筑主体竖直线在**顶部和底部**对应布设

### 操作
- 经纬仪正倒镜法，或免棱镜全站仪
- 测定每对上下观测点标志间的水平位移分量
- 按**矢量相加法**求得倾斜量和倾斜方向

依据：[[GB_T_50344-2019#条文D.0.3]]
