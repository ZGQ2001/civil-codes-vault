# 倾斜检测

> ⚠️ **区分两个概念**：
> - **构件垂直度** = 单根柱/墙的倾斜（验收项，GB 50205/50204）
> - **建筑整体倾斜** = 整栋楼的侧向位移（鉴定项，DB11/T 637）

---

## 一、构件垂直度（验收用）

### 钢柱 — GB 50205-2020 表 10.3.4

| 项目 | 允许偏差 |
|------|---------|
| 倾斜率 | **≤ 1/1000** |
| 柱顶位移 | **≤ 10.0mm** |

抽样：10%，≥3 件

### 混凝土柱 — GB 50204-2015

| 类型 | 允许偏差 |
|------|---------|
| 现浇柱 | 见表 8.3.2（按层高分档） |
| 预制柱 | 见表 9.3.9（按层高分档） |

抽样：10%，≥3 件

---

## 二、建筑整体倾斜（鉴定用）

### 允许值（按高度分级）

| 建筑高度 H_g | 允许倾斜 |
|-------------|---------|
| ≤ 24m | **≤ 0.004** |
| 24m < H_g ≤ 60m | **≤ 0.003** |
| 60m < H_g ≤ 100m | **≤ 0.0025** |
| > 100m | **≤ 0.002** |

依据：DB11/T 637 表 11.2.6（北京地标，国内通用）

### 测量方法

| 步骤 | 内容 |
|------|------|
| 测站点 | 与倾斜方向一致（或正交）的方向线上，距目标 1.5~2.0 倍高度 |
| 测站数量 | ≥ 2 个 |
| 观测点 | 建筑顶部和底部对应布设，沿竖直线 |
| 仪器操作 | 经纬仪正倒镜法 / 免棱镜全站仪 |
| 计算方法 | 测定水平位移分量 → 矢量相加法求倾斜量和方向 |

依据：JGJ 8-2016 变测规 · GB/T 50344-2019 §D.0.3

---

## 三、验收 vs 鉴定

| 维度 | [A] 新建验收 | [B] 既有鉴定 |
|------|-------------|-------------|
| 检测对象 | 构件垂直度 | 构件垂直度 + 建筑整体倾斜 |
| 判定标准 | GB 50205/50204 表值 | DB11/T 637 表 11.2.6 |
| 结论形式 | 合格/不合格 | au/bu/cu/du 变形评级 |
| 超限处理 | 返工 | 计入结构分析，评估整体稳定性 |

> ⚠️ 既有鉴定严禁直接因倾斜超验收限值判"构件不合格"。倾斜超限 → 进入变形评级，由承载力校核决定最终等级。

### calc_tilt 伪代码
```
输入: tilt_value, building_height_Hg, mode ∈ {验收, 鉴定}
判定:
  if mode == 验收:
    limit = min(H/1000, 10mm)  # 钢柱
    或 查混凝土层高分档表
  else 鉴定:
    limit = 查建筑整体倾斜表(Hg分级)
  tilt_value ≤ limit → PASS
输出: CalcResult(passed, tilt_value, limit)
```

## 方法 → 经纬仪（正倒镜法） · 免棱镜全站仪
## 判定 → GB 50205-2020 表 10.3.4 · DB11/T 637 表 11.2.6
## 出处 → GB 50205-2020 §10.3.4 · GB 50204-2015 表 8.3.2 · JGJ 8-2016 · GB/T 50344-2019 §D.0.3
