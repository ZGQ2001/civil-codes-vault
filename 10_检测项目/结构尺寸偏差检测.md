# 结构尺寸偏差检测

## 混凝土结构允许偏差（GB 50204-2015 表8.3.2）

| 构件类型 | 允许偏差 |
|---------|---------|
| 基础截面尺寸 | **+15mm, −10mm** |
| 柱/墙/梁截面尺寸 | **+10mm, −5mm** |
| 板厚 | **+10mm, −5mm** |

## 钢结构允许偏差（GB 50205-2020 条文8.5.1）

| 项目 | 偏差 |
|------|------|
| 截面几何尺寸 | **±3.0mm**（主控项目） |
| 单层柱/梁安装孔距 | ±1.0mm |

## 验收抽样

- 梁/柱：抽取构件数量 **1%**，≥3 个
- 墙/板：按自然间抽取 **1%**，≥3 间
- 层高：按自然间抽查 **1%**，≥3 间
- 依据：[[GB_50204-2015#附录F.0.1]]

## 检测方法
- 直接量测（优先）
- 局部打孔量测
- 超声测厚仪

### calc_section_dim 伪代码
```
输入: measured, design, member_type ∈ {柱/墙/梁, 板, 基础}
判定:
  delta = measured - design
  查表获取 (upper, lower) 允许偏差
  lower ≤ delta ≤ upper → PASS
输出: CalcResult(passed, delta)
```
