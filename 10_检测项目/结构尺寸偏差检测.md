# 结构尺寸偏差检测

> ⚠️ **截面尺寸公差来源**：**产品标准**（GB/T 33814 / GB/T 11263 / GB/T 706 等），非施工验收标准。
> GB 50205 的 ±3~4mm 是**构件安装后**的几何偏差，与原材料截面公差是两套体系。

---

## 一、钢结构 — 型材截面尺寸公差

### 检测流程（SOP-01）
1. 确认型材类别（焊接H型钢 / 热轧H型钢 / 工字钢 / 角钢）
2. 每构件在截面高度、宽度、腹板厚、翼缘厚四个维度至少 3 个测点
3. 高度/宽度用钢卷尺；腹板/翼缘厚度用超声测厚仪
4. 对照下表，各测点偏差 ≤ 允许偏差 → 该测点合格
5. 批判定：按 GB/T 50344 做计数抽样

- 墙/板：按自然间抽取 1%，≥3 间

## 验收 vs 鉴定

| 维度 | [A] 新建验收 | [B] 既有鉴定 |
|------|-------------|-------------|
| 核心逻辑 | 合格/不合格 | 按实测尺寸计入承载力校核 |
| 偏差超限处理 | 不合格，需返工 | ≤1.5倍→按设计值计算；>1.5倍→按实测最小值计入 |
| 最终结论 | 通过/不通过 | au/bu/cu/du 评级 |

### calc_section_dim 伪代码
```
输入: measured, design, product_type ∈ {焊接H型钢, 热轧H型钢, 工字钢, 角钢, 钢板, 现浇混凝土, 预制混凝土, 砌体}
判定:
  查对应产品标准公差表
  delta = measured - design
  |delta| ≤ 允许偏差 → PASS
  (鉴定场景: delta ≤ 1.5×允许偏差 → 按设计值; 否则按实测最小值)
输出: CalcResult(passed, delta, limit)
```
