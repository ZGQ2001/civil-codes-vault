# 筑核 · 规范知识库

土木工程检测规范 Obsidian vault。**双轴架构**：

- **检测项目 → 方法 → 判定 → 规范原文**（工作流轴，日常入口）
- **规范编号 → 条文原文**（溯源轴，证据链末端）

## 目录结构

```
00_MOC/          总索引
10_检测项目/      按检测对象索引
20_检测方法/      操作步骤、适用条件
30_判定依据/      验收标准、阈值表
40_规范原文/      条文原文（按规范分条目录入）
90_模板/          新建笔记模板
99_废止/          已废止规范（保留链接不断）
```

## 使用方式

1. 在 Obsidian 中打开本仓库
2. 从 `00_MOC/按检测项目.md` 进入
3. 沿项目 → 方法 → 判定 → 条文链路查找
4. 图谱视图可直观看到规范间引用关系

## 数据来源

规范原文来自 NotebookLM `土木工程规范` 笔记本（160+ 本 PDF），通过 Hermes → 张广奇 → NotebookLM 中继提取。
