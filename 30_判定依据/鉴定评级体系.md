# 鉴定评级体系

## 三套体系

### 安全性评级（下标 u）
| 层次 | 等级序列 | 对象 |
|-----|---------|------|
| 构件 | aᵤ / bᵤ / cᵤ / dᵤ | 单个构件 |
| 子单元 | Aᵤ / Bᵤ / Cᵤ / Dᵤ | 地基基础/上部承重结构 |
| 鉴定单元 | Aₛᵤ / Bₛᵤ / Cₛᵤ / Dₛᵤ | 整栋建筑 |

### 使用性评级（下标 s）
| 层次 | 等级序列 |
|-----|---------|
| 构件 | aₛ / bₛ / cₛ |
| 子单元 | Aₛ / Bₛ / Cₛ |
| 鉴定单元 | Aₛₛ / Bₛₛ / Cₛₛ |

### 可靠性评级（综合）
| 层次 | 等级序列 |
|-----|---------|
| 构件 | a / b / c / d |
| 子单元 | A / B / C / D |
| 鉴定单元 | **Ⅰ / Ⅱ / Ⅲ / Ⅳ** |

## 混凝土构件安全性
- 主要构件 R/(γ₀S): ≥1.00=aᵤ, ≥0.95=bᵤ, ≥0.90=cᵤ, <0.90=dᵤ
- 一般构件 R/(γ₀S): ≥1.00=aᵤ, ≥0.90=bᵤ, ≥0.85=cᵤ, <0.85=dᵤ
- 构造评定：结构构造、连接节点、预埋件三项
