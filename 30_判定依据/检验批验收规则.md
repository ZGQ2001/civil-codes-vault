# 检验批验收规则

## 基本要求
1. **主控项目**：经抽样检验均应合格
2. **一般项目**：计数抽样合格点率 ≥80%，且不得有严重缺陷（[[GB_50300-2013]] 规定按附录 D 判定）
3. 应具有完整的质量检验记录

## 抽样原则
- 随机抽取，分布均匀、具有代表性
- 明显不合格个体可不纳入检验批，但应处理后重新验收

## 最小抽样数量（GB 50300）

| 检验批容量 | 最小抽样 |
|----------|---------|
| 2~15 | 2 |
| 16~25 | 3 |
| 26~90 | 5 |
| 91~150 | 8 |
| 151~280 | 13 |
| 281~500 | 20 |
| 501~1200 | 32 |
| 1201~3200 | 50 |

## 错判/漏判概率
- 主控项目：α≤5%, β≤5%
- 一般项目：α≤5%, β≤10%

## 检验批容量扩大
- 条件：连续三批一次合格
- 幅度：扩大一倍（仅一次）
- 不合格时：按原容量重新验收，不得再次扩大
